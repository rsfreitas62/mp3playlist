HOW TO EXPORT FROM MP3TAG

  1. In Mp3tag: File → Export…
  2. Choose html (the personal template)
  3. — or — choose csv · tsv for a lighter file
  4. Load it on the left side drop zone

CSV · TSV FORMATS (if you create a custom export)

Columns in order, semicolon-separated:
STATS: Tracks;Size;Duration;Quality;Updater
TABLE: #;Artist;Title;Album;Length;Year;Country;Genre
First line can be a header row — it will be skipped automatically.
